Вспомогательные функции скриптов воспроизведения: вывод замеров (`head`, `say`, `done`),
BOP-проверка одной строкой (`bop`), поиск швов (`seam_edges`), стенд минимальной пары для шва.

```python

                                "..", "..", "..", "..", "common", "python"))
```

## Проверять тела только `check(True)`, не `isValid()`

`Part.Shape.isValid()` — дешёвая структурная проверка OCCT (`BRepCheck_Analyzer`).
`Part.Shape.check(True)` — проверка аргументов булевых операций (`BOPAlgo_ArgumentAnalyzer`),
от которой зависит всё дальнейшее. Во всех дефектах этого репозитория встречались тела, которые
`isValid()` пропускает, а `check(True)` — нет: скругление, снявшее вдвое больше нужного
(001, `issues/001-occt-fillet-at-seam/docs/MEASUREMENTS.md`, раздел 4), и резьба с отрицательным объёмом (002). Любой замер
здесь считает результат верным только при чистом `check(True)` и верном объёме.
