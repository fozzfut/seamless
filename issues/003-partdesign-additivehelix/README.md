# 003. `PartDesign::AdditiveHelix` ломается при профиле в шаг и молча съедает сердцевину

| | |
|---|---|
| Чей | FreeCAD, PartDesign (`PartDesign::AdditiveHelix`) |
| Статус | **измерено**, причина не искалась |
| Версии | FreeCAD 1.1.1, OCCT 7.8.1, Windows |
| Воспроизведение | `repro/python/09_helix_profile.py` |

Профиль — треугольник `(8.8, -h) (8.8, +h) (10.0, 0)`, заметается вокруг Z над цилиндрической
подложкой радиуса 9.0, 2 витка. Важный параметр — отношение осевого размера профиля `2h` к шагу.

## Симптом 1: инструмент невалиден ровно при `2h == pitch`

```
  h       pitch   2h/p      tool valid  free    faces   body volume
  0.990   2.0     0.990     True        0       11          1119.2513
  1.000   2.0     1.000     False       4       13          1120.3224
  1.010   2.0     1.010     True        0       11          1121.3950

  1.485   3.0     0.990     True        0       11          1678.8768
  1.500   3.0     1.000     False       4       13          1680.4833
  1.515   3.0     1.010     True        0       11          1682.0916
```

При `2h/p = 1.000`, и только при нём, у инструмента четыре свободных ребра, FreeCAD печатает
`Tool shape is not valid for boolean operation`. Обе величины шага отказывают в одной точке —
дело в отношении. Это ровно классический ISO-треугольник, у которого осевой размер равен шагу.

## Симптом 2: выше отношения 1.20 тело теряет сердцевину, а фича «в порядке»

`pitch = 3.0`, объём подложки `pi * 9^2 * 6 = 1526.8140` мм³:

```
  2h/p      tool valid  body valid  body volume   kept      State
  1.2000    True        True            1712.9123    112.2% ['Up-to-date']
  1.2100    True        True             251.8000     16.5% ['Up-to-date']  <-- CORE GONE
  1.5000    True        True             312.1487     20.4% ['Up-to-date']  <-- CORE GONE
  1.7500    True        True             364.1735     23.9% ['Up-to-date']  <-- CORE GONE
  2.0000    True        True            1526.8140    100.0% ['Touched', 'Invalid']
```

Граница резкая: 1.2000 — 112.2 %, 1.2100 — 16.5 %. Добавление материала уменьшает объём в
семь раз, а фича рапортует `['Up-to-date']`. Честный отказ появляется только при 2.0.

## Почему это PartDesign, а не OCCT

Тот же профиль при том же отношении через `Part.makePipeShell` даёт валидный инструмент и
сохранённую сердцевину:

```
  the SAME 2h == pitch triangle, Part.makePipeShell:
    faces = 5  isValid = True  free edges = 0  volume = 138.7328  t = 0.005 s
  rod.fuse(that): faces = 11 isValid = True volume = 1120.3229  (kept 110.1%)  check(True) = clean
```

## Что это не

Не шов: у подложки шов есть всегда, а у чистого результата при `2h/p = 0.90` швов нет.
Четыре «шва» при `2h/p = 1.00` — свободная граница невалидного инструмента.

## Что не сделано

Код `FeatureHelix` в FreeCAD не читался, причина не установлена.
