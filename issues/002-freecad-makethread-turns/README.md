# 002. `Part.makeThread` выдаёт долю одного витка

| | |
|---|---|
| Чей | FreeCAD, модуль Part (`Part.makeThread`) |
| Статус | **измерено**, причина не искалась |
| Версии | FreeCAD 1.1.1, OCCT 7.8.1, Windows |
| Воспроизведение | `repro/python/08_thread_turns.py` |

## Симптом

`Part.makeThread(pitch, depth, height, radius)` должен строить резьбу высотой `height`. Число
витков на деле почти не зависит от запрошенной высоты, а начиная с 8 запрошенных витков объём
отрицательный — тело вывернуто наизнанку. Шаг 2.0, глубина 1.0, радиус 9.0:

```
  asked h    asked turns  ZLength     ang. span   delivered volume
  1.0        0.50         2.2716      359.4       0.9984    +142.1177
  2.0        1.00         2.5660      357.7       0.9937    +140.6532
  4.0        2.00         3.2114      351.1       0.9751    +134.9771
  8.0        4.00         4.6010      326.1       0.9058    +115.0200
  16.0       8.00         7.1734      247.4       0.6871    -66.1129
  32.0       16.00        10.0594     84.7        0.2353    -6.8783
  64.0       32.00        11.7851     96.8        0.2690    +34.7064
```

Запрос на 32 витка:

```
  Part.makeThread(2.0, 1.0, 64.0, 9.0)
    faces = 4 edges = 6 vertexes = 4
    ZLength = 11.7851 mm (asked 64.0)
    angular span = 96.8221 deg = 0.2690 turns  (asked 32)
    volume = +34.7064   isValid = True   seams = 0
```

`isValid() = True` при отрицательном объёме: проверка структуры этого не ловит.

## Что это не

Не шов цилиндра: у полученного тела швов нет вовсе (`seams = 0`). Жалоба «резьба выходит
одним витком, от шва до шва» относится именно к этой функции.

## Обход, измеренный

Спираль через `Part.makeHelix` или `Part.makeLongHelix` и заметание профиля дают полное число
витков: запрос на 32 витка прошёл за 0.054 с и дал 32.9994 витка по высоте. Приваривание такой
резьбы к стержню — отдельная беда, дефект 005.
