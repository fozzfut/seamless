# 005. Приваривание длинной резьбы к стержню: 41 с и вывернутое тело

| | |
|---|---|
| Чей | **не определено**, вероятнее всего булевы операции OCCT |
| Статус | **измерено один раз**, не доизмерено |
| Версии | FreeCAD 1.1.1, OCCT 7.8.1, Windows |
| Воспроизведение | `issues/002-freecad-makethread-turns/repro/python/08_thread_turns.py`, последний блок |

## Симптом

Резьба на 32 витка, заметённая по спирали, сама по себе в порядке. Сращивание её со стержнем —
нет:

```
  sweep of 32 turns: faces = 5 isValid = True volume = 2467.0884  t = 0.054 s
  swept ZLength = 65.9988 mm (asked 64.0) -> 32.9994 turns
  rod.fuse(thread): faces = 90 isValid = False volume = -9596.8328  t = 41.183 s
  seams on the result = 39 ; check(True) = RAISED No error x70, Unorientable shape x36
```

Заметание — 0.054 с; `fuse` — 41.183 с, невалидное тело с отрицательным объёмом и 39 швами.

## Что известно рядом

С двумя витками и профилем через `Part.makePipeShell` тот же `fuse` чист и занимает 0.064 с
(дефект 003, раздел «Почему это PartDesign»). То есть беда проявляется на длинной спирали, а не
на резьбе вообще.

## Что нужно измерить, прежде чем что-то утверждать

1. Зависимость времени и валидности от числа витков: 2, 4, 8, 16, 32.
2. Тот же `fuse` через `BRepAlgoAPI_Fuse` в чистом OCCT, без FreeCAD, — чтобы назначить владельца.
3. Совпадают ли 39 швов результата с границами витков спирали.
